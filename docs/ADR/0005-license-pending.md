# ADR-0005: licença temporariamente não definida

- Status: aceito temporariamente
- Data: 2026-10-06

## Contexto

O projeto pretende ser aberto, mas ainda não há inventário final de componentes
do backend de Libras nem análise das condições de redistribuição do VLibras.

## Decisão

Não declarar uma licença open source antes da auditoria. Manter aviso explícito
de direitos reservados e selecionar uma licença antes da primeira distribuição.

## Alternativas consideradas

- escolher permissiva imediatamente: pode conflitar com distribuição conjunta;
- copiar a licença de um backend: ela pode não refletir o código do SINAL;
- omitir aviso: deixa a situação menos clara para colaboradores.

## Consequências

O código ainda não pode ser tratado como open source ou redistribuído. Esta ADR
deve ser substituída por uma decisão de licença antes do lançamento público.
